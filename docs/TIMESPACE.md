## 0. 先算清"卡在哪"（可复核）

| 量 | 现值 | 依据 |
|---|---|---|
| 永恒门槛 | `IP ≥ 1e308.25` | `ETERNITY.goalLog10` |
| 每次永恒的 EP | `5^(log10(IP)/308 − 0.7)`；`IP = 1e308.25` ⇒ **≈1.62 EP** | 同上 |
| 七巧板第一抽 | **1e8 EP** | `TANGRAM_ACQUIRE.epThresholds[0]` |
| 暗物质价格 | `1,3,9,27,…` | `DARK_MATTER` |

```
一次永恒 ≈ 1.6 EP，而七巧板第一抽要 1e8 EP ⇒ 差 7.8 个数量级 ✗
⇒ 永恒层**自己**永远送不到；必须有一层专门抬 EP ✓
```

## 1. 三层结构（本次设计的关键）

```
永恒（1e308.25 IP）
   ↓  第一次永恒之后解锁
空间膨胀          ← 本页新增的**中层**：唯一职责 = 把 EP 抬上去
   ↓  EP 峰值 ≥ 1e40
时空              ← 外层的**重置层**：重走一遍，带着永久乘区
```

**为什么必须分两层**（不合成）：
- 空间膨胀职责**单一**：`EP ×f(SE)`；不需要重置循环 ⇒ 节奏短、反馈快 ✓
- 时空职责是**重置 + 永久乘区**；若它同时负责"第一次抬 EP"，玩家第一次就要面对"什么都重置" ✗
- ⇒ 先"抬 EP"（几轮），再"重走"（长循环）✓ 这就是 AD 的 `Dilation → Reality` 形状 ✓

## 2. 空间膨胀系统（中层，本次新增）

### 2.1 解锁与货币

| 项 | 定义 |
|---|---|
| 解锁 | **第一次永恒**之后（不需要额外里程碑）✓ |
| 货币 | **膨胀度 SE** |
| 获取 | `SE = ⌊10^( log10(EP峰值) / 40 − 7 )⌋` |
| 端点 | EP 峰值 `1e8` ⇒ ≈0 ✗ ｜ `1e308` ⇒ ≈**5** ✓ ｜ `1e400` ⇒ ≈**1000** ✓ |

⇒ 第一次永恒后立刻能拿 **~5 SE** ⇒ 有按钮可点 ✓

### 2.2 三条升级（全 knee / 结构性 ⇒ 不动 `p`）

| 升级 | 形状 | 端点 | 作用 |
|---|---|---|---|
| **A. 空间张量** | `EP ×(1 + 1e8·x/(1+x))`，`x = SE/20` | `SE=20` ⇒ ×5e7；`SE=200` ⇒ 饱和 ≈×1e8 | **主推手**：把 1.6 EP 抬到 ~1e8 ⇒ 够到七巧板第一抽 ✓ |
| **B. 膨胀价格** | 每次膨胀后"下次价格" ×1.8 | — | 提供节奏（每轮 3~8 次膨胀）|
| **C. EP 指数** | `EP = 5^(log10(IP)/308 − 0.7 + 0.0002·SE^0.5)` | `SE=1e4` ⇒ +0.02 ⇒ ×1.05 | 长期推上限（很慢）|

**红线自检**：三条都不让 IP 反馈回 IP ⇒ `p` 不动 ✓

### 2.3 期望表（空间膨胀只做"抬 EP"）

| 轮次 | 到达 EP 峰值 | 本轮 SE | 累计 SE | A 的倍率 | 玩家感受 |
|---|---|---|---|---|---|
| 1 | 1e308（首次永恒）| ~5 | 5 | ×1.03 | 有按钮可点，但很小 ✓ |
| 2 | 1e310 | ~8 | 13 | ×1.1 | 还看不出变化 |
| 3 | 1e320 | ~15 | 28 | ×2.4 | **开始明显** |
| 4 | 1e340 | ~30 | 58 | ×8 | 每轮翻倍 |
| 5 | 1e380 | ~60 | 118 | ×50 | **EP 已到 1e3 量级** |
| 7 | 1e420 | ~150 | 400 | ×5e3 | 七巧板抽/兑开始可负担 ✓ |
| 9 | 1e460 | ~300 | 1000 | ×5e4 | **EP 到 1e8 ⇒ 时空解锁线** ✓ |
| 10 | — | — | ~1500 | 饱和（knee 之后）| 进入时空 ✓ |

⇒ 约 **9~10 轮**（每轮 5~15 min）从 1.62 EP/次 走到 1e8 EP，然后交给时空 ✓

## 3. 时空层（外层，职责 = 重置 + 永久乘区）

**解锁**：`EP 峰值 ≥ 1e40`（空间膨胀第 ~5 轮自然满足 ✓）

**重置**：EP / 永恒次数 / IP / 无限升级 / 虚空 / ZPE / 坍缩里程碑 / 量子 / SE 与 A 的倍率
**保留**：暗物质 + 暗能量里程碑、梦想点与全部升级与开关、七巧板全部、TP 与时空升级、**已买的 SE 升级等级**

**货币**：`TP = ⌊10^( log10(EP峰值) / 60 − 4 )⌋`

**三条升级**（同形制，更慢更强）：
- A. 时空张量：`EP ×(1 + 1e10·x/(1+x))`，`x = TP/100`
- B. IP 起跑线：永恒后保留 `10^(0.5·log10 TP)`，封顶 `1e150`
- C. SE 起跑线：时空后**保留一半 SE**（重走加速）

**期望表**

| 轮次 | EP 峰值 | 本轮 TP | 累计 TP | 新增能力 | 耗时 |
|---|---|---|---|---|---|
| 1 | 1e40 | ~2 | 2 | A 第 1 级 | 25 min |
| 3 | 1e100 | ~10 | 25 | B 起跑线 | 20 min |
| 6 | 1e300 | ~50 | 200 | A 到 knee | 18 min |
| 10 | 1e800 | ~300 | 3e3 | C 保留一半 SE | 15 min |
| 20 | 1e3000 | ~1e5 | 1e6 | 长尾（每轮 1 阶）| 12 min |
| **30** | **e1e5** | ~1e7 | 1e8 | **该做下一层的时机** | 12 min |

## 4. 与现有系统的衔接（只接，不加新机制）

| 现有 | 怎么用 |
|---|---|
| 七巧板 | 空间膨胀把 EP 抬到 1e8 ⇒ 抽/兑买得起 ✓；`spaceCount` 种子等时空实装后接上 |
| 暗物质 | 两层都**保留** ⇒ 成为"重走"的加速器 ✓ |
| 梦想自动化 | 保留 ⇒ 重走时自动买回，减少点击 ✓ |
| 自动无限 | 保留开关 ⇒ 重走时自动坍缩 ✓ |

## 5. 落地顺序（先测后做）

1. config 加**空间膨胀**的表（SE 公式 + 三条升级，唯一数据源）
2. 引擎：`spaceGain(state)`、`buySpaceUpgrade(id)`（不改任何公式形状）
3. 断言：① SE 三个端点（1e8 / 1e308 / 1e400）② 三条升级 knee 单调 + 封顶 ③ 未解锁时恰好 0
4. `stage-timing` 实测：**每轮 5~15 min**、**9~10 轮**到 1e8 EP ⇒ 与 §2.3 对齐
5. UI：空间膨胀页（SE、三条升级、下一次膨胀的价格）
6. 时空等空间膨胀**验收通过**后再做（它需要 SE 作"起跑线"输入 ✓）

**验收标准**：
- 空间膨胀：首次永恒 → EP ≥ 1e8 **≤ 10 轮**，每轮 **≤ 15 分钟** ✓
- 时空：解锁后 **≤ 3 轮**能负担七巧板第一抽 ✓
