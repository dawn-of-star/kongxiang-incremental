## 6. 强度评估（重写时请一起决定）

用真实换算（`EP = 5^(log10 IP/308 − 0.7)`，每 +1 阶 IP ⇒ EP ×1.0052）：

| 项 | 折算成什么 | 强不强 |
|---|---|---|
| `epDiscount` 90% | 巧板自身体系内（更便宜地抽/兑）| 强 ✓ 但**只服务七巧板自己**（自循环）|
| `convSlopeMult ×10` | +1 阶材料 ⇒ +6.2 阶 IP ⇒ **EP ×1.03** | **很弱** ✗ |
| `countFreqMult ×5` | 同上量级 | **很弱** ✗ |

| `deKneeMult ×4` | knee 右移 ⇒ 暗能量曲线在后期更陡 | 中 ✓ |
| `passiveIpFrac 1%/s` | 线性补 IP（快照制）| 中 ✓（不构成指数 ✓）|
| `allClear` deGain 1.12→1.14 | 每级多 1.8% ⇒ 长期复利 | **中偏强** ✓ |

**结论**：现有奖励里 **没有一项直接抬 EP** ✗ ⇒ 全部走 IP 侧/体系内折扣 ⇒ 对"把 EP 推到更高位置"这个**目标**几乎无感 ✗（这也是你上次说的 +120 阶没感觉 ✓）
