## 5. 可达性核算（**本页最重要的部分**）

用户提出的组合：「七巧板每秒 1% 本次无限 IP（自增长）+ 量子数量 + du7 ⇒ **爆 IP 换 EP**」✓
方向对 ✓，但**速度**不够 ✓，实算如下。

### 5.1 EP 需要多少 IP

```
EP = 5^(log10(IP)/308 − 0.7)
EP = 1e8  ⇒  log10(IP) = 3741   （IP ≈ 1e3741）
现在      ⇒  log10(IP) = 308.25
还差      ⇒  3433 个数量级
```

### 5.2 IP 自增长能涨多快

`dIP/dt = 0.01 × bigCrunchGain`，而 `bigCrunchGain ∝ IP^p` ⇒ `IP ∝ t^(1/(1−p))`：

| 场景 | p | 3 小时（12 轮 × 15 分）能涨 |
|---|---|---|
| 模式外 | 0.301 | **5.8 个数量级** |
| 模式内（`^0.5`）| 0.150 | **4.7 个数量级** |
| 想 3 小时涨够 3433 阶 | 需要 **p ≈ 0.999** ✗ | 爆炸型，超红线 ✗ |

### 5.3 结论：不是设计错，是我的价格假设错

`1e8 EP` 来自 `TANGRAM_ACQUIRE.epThresholds[0]`（历史值，按"EP 会很大"设计 ✗）。
按现有 EP 公式，**EP 在合理时间内只会停在 ~1.7**（IP 涨 6 个数量级 ⇒ EP 1.62 → 1.69 ✗）。

**⇒ 待办（用户游玩后拍板）**：把七巧板的 **EP 价格表整体下调**到 EP 的真实量级
（例：`epThresholds` 从 `1e10, 1e13, …` 改成 `2, 20, 200, …`）。
这样「爆 IP ⇒ 抬 EP」依然有用（哪怕只从 1.6 → 1.7 ✓），七巧板在空间膨胀阶段就买得起 ✓，
**不动 EP 公式、不 p → 1、不碰红线** ✓

## 12. 对"新版原文（du1~du10）"的评估（2026 用户改档后）

### 12.1 新版结构

| 类别 | 项 | 效果落在哪条链 |
|---|---|---|
| **可重复（SE）** | du1 暗物质倍率 × 次数 ｜ du2 巧板有效加成 × 次数 ｜ du3 量子强度 × 次数 | **IP 侧**（DE / 巧板三轴 / 量子 → IP） |
| | du4 巧板免费引擎数 × 次数 ｜ du5 巧板熵→粒子倍率 × 次数 ｜ du6 计数频率倍率（次数的开根）| **IP 侧** |
| **单次（ST）** | du7 量子按个数 ｜ du8 zpe 价格削弱 ｜ du9 虚空强度 ∝ 量子数 ｜ du10 zpe 倍率对膨胀升级价格修正 | **IP 侧 / 价格** |

⇒ **十项全部是 IP 侧或价格侧，没有一项直接抬 EP** ✓（这本身不是错，但决定了"要多强才够"）。

### 12.2 关键换算（这就是"为什么 +120 阶没感觉"）

```
EP = 5^(log10(IP)/308 − 0.7)   ⇒ 每 +1 阶 IP，EP 只 ×1.0052
```

| IP 增量 | EP 倍数 |
|---|---|
| +120 阶（巧板三轴全满） | **×1.87** ← 这就是你说的"基本没变化" ✓ |
| +500 阶 | ×13.6 |
| +1232 阶 | ×619（EP 1.6 → 1e3）|
| **+3434 阶** | **×6.1e7（EP 1.6 → 1e8）** |

⇒ **要让 EP 真的上去，du1~du6 必须能给出"上千阶的 IP"** ✗ 而不是几百阶。

### 12.3 因此决定成败的是**效果曲线的形状**，不是项数

| 形状 | 例 | n=100 时的效果 | 能否到 +3434 阶 |
|---|---|---|---|
| **knee 饱和**（`1 + A·n/(1+n/k)`）| 我们七巧板用的那种 | 最多 ×(1+A) ⇒ 有限 | **不能** ✗（封顶）|
| **线性**（`×(1+0.5n)`）| — | ×51 ⇒ +1.7 阶 | **不能** ✗ |
| **幂律**（`×n^2`）| — | ×1e4 ⇒ +4 阶 | 勉强 ✗ |
| **指数**（`×2^n`）| AD 的很多复购升级 | **+30 阶** | 可行 ✓（配合足够便宜的价格）|
| **指数 × 开根**（`×2^√n`）| du6 的写法暗示这个 | +10 阶 | 需配合其他项 ✗ |

⇒ **建议**：du1 / du2 / du3 用 **`×2^n`** 或 **`×3^n`**（**不封顶** ✗ 不要 knee），
价格用 **`×1.15^n` ~ `×1.3^n`**（比效果增长慢得多 ✓）⇒ 玩家能一路买上去，
**到 n≈100~150 时累计 +3000 阶 IP ⇒ EP 真的抬到 1e8** ✓

### 12.4 挑战模式的 `^0.5` 会吃掉一半

```
模式内：最终收益 ^0.5  ⇒ log 空间减半 ⇒ 同样的 du 只给**一半**的阶数
⇒ 想拿 +3434 阶，模式内需要 du 提供 **+6868 阶**（或靠退出模式后的结算）
```
⚠️ 因此 du 的强度要按 **×2** 预留 ✓（或允许"在模式内买 du、退出后再吃收益" ✓）

### 12.5 判定结论

| 问题 | 答案 |
|---|---|
| 新档的 **10 项**够不够多 | **够** ✓（6 复购 + 4 单次，覆盖面完整）|
| 新档的 **强度**够不够 | **取决于 du1~du6 的形状**：<br>· 如果沿用七巧板那种 **knee 饱和** ⇒ **不够** ✗（EP 至多 ×几倍）<br>· 如果用 **`×2^n` 级指数** ⇒ **够** ✓（能到 EP 1e8）|
| 还需要什么 | ① du1~du3 用**不封顶**的指数效果 ② 价格增长率 < 效果增长率 ③ 按 `^0.5` 预留 ×2 |
